# 画廊分屏插件

独立补充油猴脚本，使用 Chrome 原生 Split View。官方分屏操作 API 标注为 Chrome 155+；运行时仍会检查接口是否开放。本机开发环境为 Chrome 154，尚未实测原生分屏。

## 安装

1. 在支持分屏 API 的 Chrome 打开 `chrome://extensions`，开启“开发者模式”。
2. 点击“加载已解压的扩展程序”，选择本目录 `extension`。
3. 从列表打开新画廊：详情留在左侧，首个可见缩略图对应的阅读页自动放在右侧。原有油猴脚本可继续使用。

同时使用 eh工具 0.5.0+ 油猴脚本时，右侧图片页自动进入纵向连续阅读；此插件本身仍只负责分屏配对。

普通左键点击左侧缩略图会在右侧阅读页跳转；阅读页正常翻页。Ctrl / Shift / 中键保留浏览器行为。点击扩展图标暂停或启用，设置持久保存。刷新详情不会重复开阅读页；关闭阅读页或手动解除分屏后，点击缩略图可重新配对。

后台打开画廊时不会主动切换焦点。已有其他分屏的画廊不被拆散。两站分别配对，不跨站匹配；不自动打开 MPV，不获取额外画廊页面或图片。

图标出现 `!` 时，悬停查看原因。接口不可用时不打开阅读页；更新浏览器后刷新画廊重试。仅使用 `storage` 与两站权限，没有运行时依赖。

API：[Chrome Tabs](https://developer.chrome.com/docs/extensions/reference/api/tabs#method-createSplit)。
