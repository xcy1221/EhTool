# eh工具

用于 e-hentai / exhentai 的左侧浮动 Tampermonkey 工具，可与 EhSyringe 一起使用。保存标签历史，组合标签、页数和评分条件。

仓库：[xcy1221/EhTool](https://github.com/xcy1221/EhTool)。面板宽 540 px，小屏幕自动适配。

## 安装与更新

**更新地址须可公开访问**：私有仓库的 GitHub Raw 地址会返回 404。使用下方链接前需公开本仓库，或将两个发布文件放到无需登录的地址，并修改 `scripts/build.mjs` 中的更新与下载 URL。

1. 在浏览器安装 [Tampermonkey](https://www.tampermonkey.net/)。
2. 点击 [安装 / 更新 eh工具](https://raw.githubusercontent.com/xcy1221/EhTool/main/dist/eh-search-tool.user.js)，在油猴页面确认安装或更新。
3. 刷新 EH / EX 页面。搜索页左侧显示浮动面板，画廊详情页提供评论区收起按钮，普通图片页支持连续阅读。

**旧版迁移只需一次**：之前手动粘贴代码的用户，也通过上面的链接更新现有脚本；保留原脚本的名称与 namespace，不先卸载，原有历史、组合和设置会保留。若链接仅显示源码，可将链接粘贴到油猴“实用工具 → 从 URL 安装”。

从 0.5.4 起，脚本自带检查更新和下载地址。在油猴中启用此脚本的更新检查后，可按油猴设置的周期检查，也可手动点击“检查更新”；完成更新后刷新已打开的页面，无需再复制代码。检查更新只下载小型元数据文件，有新版时才下载完整脚本。

| 地址 | 用途 |
| --- | --- |
| [eh-search-tool.meta.js](https://raw.githubusercontent.com/xcy1221/EhTool/main/dist/eh-search-tool.meta.js) | 检查版本（更新地址） |
| [eh-search-tool.user.js](https://raw.githubusercontent.com/xcy1221/EhTool/main/dist/eh-search-tool.user.js) | 安装及下载新版（下载地址） |

更新失败时，确认能访问上述两个地址、油猴允许此脚本检查更新；手工编辑过脚本后尤其需要检查该开关。GitHub Raw 可能有短暂缓存，新版发布后稍等再检查即可。

浏览器需要允许扩展运行用户脚本。工具依赖现有站点访问权限，不提供登录或访问功能。

## 使用

- 在“历史标签”复用用过的标签；“查找新标签”支持中英文搜索和分类。
- 先选**必须包含**（绿色）、**排除此标签**（红色）或**任一包含 OR**（蓝色），再点标签名称。同用途再点取消，换用途再点切换；已选标签也可直接切换三种用途。
- OR 标签至少满足一个，其他必须包含与排除条件仍生效。例如 `~language:chinese$ ~language:english$` 表示中文或英文；OR 用途随草稿和常用组合保存。
- 页数范围可以只填一侧，留空表示不限；最低评分支持不限或 2–5 星。
- 填入页数或星级筛选时会先点击原站高级选项，并确保提交 `advsearch=1`。工具自动恢复上次在工具内选择的星级（含“不限”）；读取原站、载入组合或提交搜索不会覆盖这项记忆。
- 工具内部编辑**不会改写原搜索栏**。底部两个按钮各占一半：“填入搜索栏”仅替换原语句、页数和评分；“填入并搜索”填入后立即通过原站表单搜索。其他原站筛选项保持原样。手机上填入后自动收起工具。
- “读取原搜索栏”将现有条件读入工具；“恢复上次组合”恢复上次草稿，包括页数、评分。“保存常用组合”可保存具名配置。
- 历史保留最近 500 个标签，关闭浏览器后仍在，两站共用。清空已选条件不会删除历史。复用历史时先选择用途；手动输入支持 `namespace:tag`，完整名称匹配可在高级设置中调整。
- 搜索语句最多 200 字符，页数应为 1–9999 的整数且最少不大于最多；无效条件无法填入，原生搜索操作不受工具限制。
- 默认在新标签页打开画廊，支持后来加载的画廊链接；可在“站点行为”关闭并恢复原打开方式。仅匹配两站的 `/g/画廊编号/标识/` 链接，不改变分页、图片页或外站链接。
- “打开画廊后切换到新标签页”默认勾选，取消后普通左键点击会在后台打开，设置关闭浏览器后保留。Ctrl / Command / Shift 点击与中键仍按浏览器习惯处理；需授予 Tampermonkey `GM_openInTab` 权限，本地演示不控制焦点。

内置少量语言与通用标签。完整词库来自 [EhTagTranslation/Database](https://github.com/EhTagTranslation/Database) 的官方发布镜像，和 EhSyringe 使用同一数据来源。仅在点击加载时请求 GitHub，不发送搜索词或站点 Cookie，不渲染描述、HTML 或图片；失败时保留旧词库。

也可导入 EhTagTranslation 的 `db.text.json`，或自定义 JSON 数组（导入会替换已加载词库，保留内置及手动标签）：

```json
[
  { "namespace": "language", "tag": "chinese", "name": "中文", "aliases": ["汉语"] },
  { "namespace": "artist", "tag": "example artist", "name": "示例作者" }
]
```

## 连续阅读与界面

- 打开普通图片页（`/s/`）后自动纵向连续阅读，按图片顺序上下滚动。默认沿浏览方向预加载 5 张、反方向保留 3 张，可见图片始终保留；转向后调整加载队列，超出范围的图片释放并保留等高占位。
- 画廊详情页评论区上方可点击“收起评论区 / 展开评论区”。搜索面板“设置 → 评论区设置”可关闭按钮或设置默认收起；默认展开，详情页切换仅影响当前页，两站共用默认设置。
- 阅读区顶部“设置”可调整张数、最大宽度、图片间距、自动重试次数与重试间隔（秒），立即生效并保存。加载失败可单张重试；“返回原页”恢复原阅读页面，左下角可再次进入。
- 面板顶部与阅读区提供明暗切换。首次使用 EH 为浅色、EX 为深色，手动选择优先并保存。
- 保留整体收起，筛选、标签选择、已选条件、常用组合、设置可独立收起并记住状态。已选条件标题显示标签数量，搜索语句及填入按钮保持容易访问。
- 搜索面板“设置 → 连续阅读设置”可关闭自动阅读、调整默认张数及重试设置。界面与阅读配置使用独立存储，不覆盖原有标签历史、草稿或常用组合。
- 油猴脚本负责连续阅读；同时安装分屏插件时，右侧普通图片页也自动使用此功能。只有分屏插件时仍为原站阅读方式。


首图复用原站图片请求。自动重试默认 1 次、间隔 3 秒，可配置 0–20 次、0–300 秒（0 次关闭，0 秒立即重试）；失败后优先获取备用来源，无重载参数时重新获取普通图片页。次数用完后可手动重试，滚出加载范围或退出阅读会取消等待中的重试。

## Chrome 画廊分屏

新增独立轻量插件，自动将画廊详情与阅读页左右配对。安装与版本要求见 [extension/README.md](extension/README.md)；需要 Chrome 开放原生分屏 API（官方标注 155+）。

## 开发与验证

```sh
npm ci
npm run check
npm run demo
npm run test:browser
npm run test:reader-browser
```

访问 `http://127.0.0.1:4173` 预览。演示使用模拟表单与基础标签，不访问目标站点；演示数据存在浏览器本地，安装版存在 Tampermonkey 持久存储，关闭浏览器不会清除。卸载脚本、手动清除扩展数据或无痕会话可能清除记录。

`src/config.js` 集中管理界面与阅读默认配置，`src/theme.css` 管理配色变量，`src/reader.js` 分开处理页面解析、加载调度与显示；分区通过 `data-section` 标识扩展。

`src/` 是源码，`npm run build` 同时生成完整脚本与更新元数据，无运行时依赖。测试覆盖原生输入不被干扰、显式填入、按需提交、评论区收起与配置、两种评分表单、包含/排除互斥、持久历史和词库失败。尚未在真实站点及实际 EhSyringe 安装环境验证；依赖原站 `f_search`、`f_spf`、`f_spt`、`f_srdd` 控件。

`npm run test:browser` 验证真实键盘输入、等宽底部按钮、填入并搜索、评论区收起、筛选参数、关闭重开及移动端布局。`npm run test:reader-browser` 使用本地模拟的 EH/EX 图片页验证顺序、5/3 窗口、转向取消、重试、占位高度、键盘和窄分屏尺寸；不访问真实画廊。截图在 `test-results/`；Windows 使用已安装的 Edge，其他环境需 `npx playwright install chromium`。

## 发布新版本

1. 使用 `npm version patch --no-git-tag-version` 同步提升 `package.json` 与锁文件版本。修改源码或文档后执行 `npm run check`；涉及界面或阅读交互时运行对应浏览器检查。
2. 将源码、文档以及生成的 `dist/eh-search-tool.user.js`、`dist/eh-search-tool.meta.js` 一起提交并推送到 `main`。构建时自动读取包版本，两个发布文件使用相同版本号。
3. 确认上面的安装与更新地址可访问且版本正确；油猴只会安装比本地版本更高的更新。保持脚本名称、namespace 和现有存储键不变。

当前版本 **0.5.4**：接入油猴更新机制；包含评论区收起配置、填入并搜索、连续阅读、明暗配色与独立分区折叠。Chrome 分屏扩展单独安装，更新该扩展后需在扩展管理页点击“重新加载”。
